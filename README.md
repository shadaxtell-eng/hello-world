# hello-world

## How to Download

There are two easy ways to get this project onto your computer:

### Option 1 – Clone with Git (recommended)

Make sure you have [Git](https://git-scm.com/downloads) installed, then run:

```bash
git clone https://github.com/shadaxtell-eng/hello-world.git
```

This will create a `hello-world` folder in your current directory with all the project files.

### Option 2 – Download as a ZIP

1. Go to the repository page on GitHub: <https://github.com/shadaxtell-eng/hello-world>
2. Click the green **Code** button near the top-right of the file list.
3. Select **Download ZIP**.
4. Extract the downloaded `.zip` file to a folder of your choice.

---

That's it! You now have a local copy of the project. 🎉
