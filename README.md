# hello-world

## How to Download This Repository

There are a few ways to get the contents of this repository onto your machine:

### Option 1: Clone with Git (recommended)

If you have [Git](https://git-scm.com/) installed, run the following command in your terminal:

```bash
git clone https://github.com/shadaxtell-eng/hello-world.git
```

This will create a local copy of the entire repository in a folder called `hello-world`.

### Option 2: Download as a ZIP

1. Go to the repository page on GitHub: https://github.com/shadaxtell-eng/hello-world
2. Click the green **Code** button near the top-right of the file list.
3. Select **Download ZIP**.
4. Extract the downloaded `.zip` file to your desired location.

### Option 3: Download a single file

1. Navigate to the file you want on the repository page.
2. Click on the file to open it.
3. Click the **Raw** button (or the download icon).
4. Right-click the page and choose **Save As…** to save the file.
