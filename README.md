# hello-world

## How to Download This Repository

There are two ways to get the files from this repository onto your computer:

### Option 1: Download as a ZIP file (no Git required)

1. Go to the main page of this repository on GitHub.
2. Click the green **Code** button near the top right.
3. Select **Download ZIP** from the dropdown menu.
4. Once the ZIP file downloads, unzip it to access the files.

### Option 2: Clone with Git

If you have [Git](https://git-scm.com/downloads) installed, you can clone the repository:

1. Go to the main page of this repository on GitHub.
2. Click the green **Code** button near the top right.
3. Copy the URL shown (HTTPS or SSH).
4. Open a terminal (Command Prompt, PowerShell, or Terminal) and run:

```bash
git clone https://github.com/shadaxtell-eng/hello-world.git
```

5. A new folder called `hello-world` will be created with all the files inside.
