# hello-world

## How to Download This Repository

You can download this repository in one of the following ways:

### Option 1: Clone with Git (recommended)

If you have [Git](https://git-scm.com/) installed, open a terminal and run:

```bash
git clone https://github.com/shadaxtell-eng/hello-world.git
```

This will create a local copy of the repository in a folder called `hello-world`.

### Option 2: Download as a ZIP file

1. Go to the repository page on GitHub: [https://github.com/shadaxtell-eng/hello-world](https://github.com/shadaxtell-eng/hello-world)
2. Click the green **Code** button near the top right.
3. Select **Download ZIP**.
4. Extract the downloaded `.zip` file to your desired location.
