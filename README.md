# Hello World 🌍

A clean, animated **Hello World** web page — the perfect starting point.

## Preview

Open `index.html` in any modern browser to see the greeting in action, or visit the live demo if deployed via GitHub Pages.

## Usage

```bash
# Clone the repository
git clone https://github.com/shadaxtell-eng/hello-world.git
cd hello-world

# Open in your browser
open index.html          # macOS
xdg-open index.html      # Linux
start index.html         # Windows
```
